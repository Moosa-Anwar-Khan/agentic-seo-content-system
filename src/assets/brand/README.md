# Bundled editorial brand assets

The logo and photographs in this public showcase are neutral generated
placeholders for the fictional firm "Muster & Partner". Replace them with the
client firm's approved assets; the manifest records each file's hash.

Font files are unmodified Google Fonts Latin subsets containing German letters
and punctuation. Montserrat and Cabin are distributed under SIL OFL 1.1;
Roboto Slab uses Apache License 2.0. License texts are included. Original
source URLs and hashes are in the manifest.

The renderer embeds these files locally; it never calls Google Fonts or a
company website to render a preview. Packaging includes this directory.
